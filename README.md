# Emin Pişkin — Beyond The Frame

Sinematik kişisel biyografi sitesi.

## Dosyalar

- `index.html` — sinematik ana sayfa ve stil/animasyonlar.
- `portrait.png` — ana sayfada kullanılacak yatay siyah-beyaz portre fotoğrafı. **Bu dosyanın GitHub'a ayrıca yüklenmesi gerekir.**

Fotoğrafı deponun kök dizinine (index.html ile aynı seviyeye) **portrait.png** adıyla yükleyin.

## Yayınlama

Bu depo Vercel'e bağlanabilir. GitHub içeriğinin canlı siteyle otomatik eşitlenmesi için Vercel Git bağlantısının ayrıca kurulması gerekir.
